# Roll-a-Ball
"Experiment 4"

Pitch du jeu : Dans ce jeu nous incarnons une créature géométrique qui peut s’adapter à son environnement en modifiant sa forme pour essayer de se défaire des pièges et obstacles qu’il rencontrera sur son chemin.
Type de jeu : puzzle Game  
Scénario : la créature vient de voir le jour et dois trouver de la nourriture, faire face aux dangers qu’il rencontrera et apprendre à survivre dans ce monde inconnu. 
Mécanique : 
Personnage : Le personnage jouable peut changer de forme pour obtenir différentes capacités :
-	Sphère : se déplace constamment mais ne peut pas attaquer ni interagir
-	Cube : ne peut que sauter et activer des mécanismes ayant besoin d’être presser par un poids
Objets interactifs : 
-	La plaque de pression (activable : Cube)
-	Cubes rouges : fait perdre des points si toucher (par tous)
-	Cubes bleus : permet de se téléporter à un autre cube bleu (par tous)
-	Cubes verts : permet de gagner des points (par tous)
But du jeu :
-	Atteindre le score de 100 point pour finir un niveau
DA :
-	Cartoon, ombrage délimiter, cernes fines noires
Levels design :
-	Représentation d’un univers ou une créature solitaire apprends la vie et comment survivre.
